# Portafolio personal — Alejandro Waigandt Stach

Portafolio web personal realizado como proyecto académico de UX/UI. Presenta la formación, las herramientas y los proyectos de Alejandro, estudiante de segundo año de la Licenciatura en Sistemas de Información.

## Secciones

El sitio conserva las nueve secciones solicitadas:

1. Encabezado y navegación.
2. Presentación.
3. Aspectos destacados.
4. Competencias.
5. Proyectos.
6. Formación y trayectoria.
7. Sobre mí.
8. Contacto.
9. Pie de página.

También incluye una página interna de caso de estudio dedicada a SmartTicket.
Las rutas inexistentes muestran una página 404 personalizada mediante el comportamiento estándar de Netlify.

## Tecnologías

- HTML5.
- CSS3, con diseño responsive y estilos para movimiento reducido.
- JavaScript nativo para el menú, la navegación y el año del pie de página.
- Google Fonts (Inter), con tipografías de respaldo.

Las herramientas y tecnologías de cada proyecto se indican en sus tarjetas cuando están verificadas en sus repositorios.

## Ejecución local

El sitio es estático y no requiere instalación de dependencias ni proceso de compilación.

1. Abrí la carpeta `TP6_Portfolio` en Visual Studio Code.
2. Instalá la extensión **Live Server** si todavía no está instalada.
3. Abrí `index.html` y seleccioná **Open with Live Server**.

También se puede abrir `index.html` directamente en un navegador; Live Server facilita la vista previa al editar.
